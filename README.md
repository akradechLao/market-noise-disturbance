# Sound Monitor Dashboard - ตลาด Bigfood แหลมฉบัง

ระบบมอนิเตอร์เสียงรบกวนสำหรับตลาด Bigfood แหลมฉบัง แสดงผลแบบ Real-time พร้อมวิเคราะห์ตามมาตรฐานกฎหมายไทย

## หน้าที่ใช้งาน

| หน้า | รายละเอียด |
|------|-----------|
| **Dashboard** | ภาพรวมข้อมูลเสียง Real-time, กราฟ Line, สถิติ, การกระจายค่าเสียง |
| **Real-time** | วิเคราะห์เสียงรบกวน (Leq-L90), กราฟรายชั่วโมง, เกณฑ์จำแนก |
| **วิเคราะห์ & รายงาน** | กำหนดช่วงเวลาเอง, ตั้งค่า Background Noise, ส่งออกรายงาน |

## คุณสมบัติ

- แสดงค่า Leq, L90, L10, LMax แบบ Real-time
- คำนวณเสียงรบกวนตามประกาศคณะกรรมการควบคุมมลพิษ พ.ศ. 2565
- ปัจจัยแก้ไขตามกฎหมาย (Thai Legal Correction Factors)
- ปรับธีม Dark/Light
- ส่งออกรายงาน PDF, CSV, HTML

## แหล่งอ้างอิงทางกฎหมาย

### ประกาศคณะกรรมการควบคุมมลพิษ

เรื่อง วิธีการตรวจวัดระดับเสียงพื้นฐาน ระดับเสียงขณะไม่มีการรบกวน การตรวจวัดและคานวณระดับเสียงขณะมีการรบกวน การคานวณค่าระดับการรบกวน และแบบบันทึกการตรวจวัดเสียงรบกวน พ.ศ. 2565

อาศัยอำนาจตาม ข้อ 3 แห่งประกาศคณะกรรมการสิ่งแวดล้อมแห่งชาติ ฉบับที่ 29 (พ.ศ. 2550) เรื่อง ค่าระดับเสียงรบกวน

ประกาศ ณ วันที่ 21 กันยายน พ.ศ. 2565 ลงนามโดย จตุพร บุรุษพัฒน์ ปลัดกระทรวงทรัพยากรธรรมชาติและสิ่งแวดล้อม ประธานกรรมการควบคุมมลพิษ

## นิยามศัพท์ตามกฎหมาย

| ศัพท์ | ความหมาย |
|-------|---------|
| **เสียงรบกวน** | ระดับเสียงจากแหล่งกำเนิดที่มีระดับเสียงสูงกว่าระดับเสียงพื้นฐาน |
| **ระดับเสียงพื้นฐาน (Background Sound Level)** | ระดับเสียงเปอร์เซ็นไทล์ที่ 90 (LA90) ที่ตรวจวัดในขณะยังไม่เกิดเสียงจากแหล่งกำเนิด |
| **ระดับเสียงขณะไม่มีการรบกวน (Residual Sound Level)** | ระดับเสียงเฉลี่ย (LAeq) ที่ตรวจวัดในขณะยังไม่เกิดเสียงจากแหล่งกำเนิด |
| **ระดับเสียงขณะเกิดเสียงของแหล่งกำเนิด (Specific Sound Level)** | ระดับเสียงเฉลี่ย (LAeq) ที่ตรวจวัดในขณะเกิดเสียงจากแหล่งกำเนิด |
| **ระดับเสียงขณะมีการรบกวน (Rating Level)** | ระดับเสียงที่คำนวณจากระดับเสียงขณะเกิดเสียง รวมทั้งบวกเพิ่มกรณีพิเศษ |
| **ระดับการรบกวน** | ค่าความแตกต่างระหว่างระดับเสียงขณะมีการรบกวนกับระดับเสียงพื้นฐาน |

## สูตรคำนวณตามประกาศ พ.ศ. 2565

### สมการที่ 1 - ระดับเสียงขณะมีการรบกวน (Rating Level)

```
LAeq,Tr = [10 log10(10^(0.1 x LAeq,Ts) - 10^(0.1 x LAeq,R))] + 10 log10(Ts/Tr)
```

โดยที่:

- **LAeq,Tr** = ระดับเสียงขณะมีการรบกวน (dB(A))
- **LAeq,Ts** = ระดับเสียงขณะเกิดเสียงของแหล่งกำเนิด (dB(A))
- **LAeq,R** = ระดับเสียงขณะไม่มีการรบกวน (dB(A))
- **Ts** = ระยะเวลาที่แหล่งกำเนิดเกิดเสียง (นาที)
- **Tr** = ระยะเวลาอ้างอิง (นาที)

### ค่า Tr ตามกฎหมาย

| กรณี | ค่า Tr |
|------|--------|
| แหล่งกำเนิดก่อให้เกิดเสียงช่วง 06.00 - 22.00 นาฬิกา | 60 นาที |
| พื้นที่ต้องการความเงียบสงบ หรือช่วง 22.00 - 06.00 นาฬิกา | 5 นาที |

### สมการที่ 2 - กรณีเสียงไม่ต่อเนื่องมากกว่า 1 ช่วงเวลา

```
LAeq,Ts = 10 log10 { (1/Ts) x Sum(Ti x 10^(0.1 x LAeq,Ti)) }
```

### ค่าบวกเพิ่ม (Additions)

| กรณี | บวกเพิ่ม |
|------|---------|
| พื้นที่ต้องการความเงียบสงบ หรือช่วง 22.00 - 06.00 นาฬิกา | +3 dB |
| เสียงกระแทก (Impulsive Noise) | +5 dB |
| เสียงแหลมดัง (High-pitched Noise) | +5 dB |
| เสียงที่มีความสั่นสะเทือน (Vibration Noise) | +5 dB |

### การคำนวณค่าระดับการรบกวน

```
ค่าระดับการรบกวน = ระดับเสียงขณะมีการรบกวน - ระดับเสียงพื้นฐาน (LA90)
```

ผลลัพธ์เป็นทศนิยม 1 ตำแหน่ง ปัดเศษตาม มอก. 929 - 2533

### เกณฑ์ตัดสิน

| ค่าระดับการรบกวน | ผลสรุป |
|------------------|--------|
| > 10 dB | **เป็นเสียงรบกวน** |
| <= 10 dB | ไม่เป็นเสียงรบกวน |

## กรณีการตรวจวัด (ข้อ 4 และ 5)

### การตรวจวัดระดับเสียงพื้นฐาน (ข้อ 4)

| กรณี | วิธีการ |
|------|--------|
| แหล่งกำเนิดยังไม่เกิด/ยังไม่มีการดำเนินกิจกรรม | วัดในวัน เวลา และตำแหน่งที่คาดว่าจะได้รับการรบกวน |
| แหล่งกำเนิดดำเนินกิจกรรมไม่ต่อเนื่อง | หยุดกิจกรรม หรือวัดทันทีก่อน/หลังการดำเนินกิจกรรม |
| แหล่งกำเนิดดำเนินกิจกรรมต่อเนื่องไม่สามารถหยุดได้ | วัดในบริเวณอื่นที่สภาพแวดล้อมคล้ายคลึงกัน |

หมายเหตุ: ต้องตรวจวัดเป็นเวลาไม่น้อยกว่า 5 นาที

### กรณีการตรวจวัดระดับเสียงขณะมีการรบกวน (ข้อ 5)

| กรณี | วิธีการ |
|------|--------|
| 5.1 เสียงต่อเนื่องตั้งแต่ 1 ชั่วโมงขึ้นไป | วัด LAeq 1 ชั่วโมง คำนวณตามสมการที่ 1 |
| 5.2 เสียงต่อเนื่องแต่ไม่ถึง 1 ชั่วโมง | วัดตั้งแต่เริ่มจนสิ้นสุด คำนวณตามสมการที่ 1 |
| 5.3 เสียงไม่ต่อเนื่องมากกว่า 1 ช่วงเวลา | คำนวณ LAeq,Ts ตามสมการที่ 2 แล้วคำนวณตามสมการที่ 1 |
| 5.4 พื้นที่ต้องการความเงียบสงบ/ช่วง 22-06 | วัด LAeq 5 นาที คำนวณตามสมการที่ 1 แล้วบวกเพิ่ม 3 dB |
| 5.5 เสียงกระแทก/เสียงแหลมดัง/เสียงสั่นสะเทือน | คำนวณตามกรณีที่เหมาะสม แล้วบวกเพิ่ม 5 dB |

## การเตรียมเครื่องมือ (ข้อ 2)

- มาตรระดับเสียงต้องได้รับการสอบเทียบไม่เกิน 2 ปี
- เครื่องกำเนิดสัญญาณเสียงอ้างอิงต้องสอบเทียบไม่เกิน 1 ปี
- ห้องปฏิบัติการต้องได้รับการรับรอง มอก. 17025 (ISO 17025)
- ปรับมาตรระดับเสียงเป็น A Frequency weighting และ Fast Time weighting

## การตั้งไมโครโฟน (ข้อ 3)

| ตำแหน่ง | ความสูงจากพื้น | รัศมีรอบไมโครโฟน |
|---------|---------------|------------------|
| ภายนอกอาคาร | 1.2 - 1.5 เมตร | 3.5 เมตร ไม่มีสิ่งกีดขวาง |
| ภายในอาคาร | 1.2 - 1.5 เมตร | 1 เมตร ห่างจากหน้าต่างอย่างน้อย 1.5 เมตร |
